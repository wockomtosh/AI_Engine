I created a C++ game engine focused on learning about AI implementation. It uses OpenFrameworks for rendering. There are 3 main parts that build off each other. In the first part I implemented various dynamic steering behaviors including arrive, evade, wander, and flocking. In the second part I implemented pathfinding using a tile graph and the A* algorithm with a couple different heuristics. In the third part I implemented decision-making behaviors including an action manager, behavior trees, decision trees, and some goal-oriented action planning.
